# Kalav Hospitality — Events Management

Premium multi-page event management website for **Kalav Hospitality** (Events Management), Bangalore.

| Route | Page |
|-------|------|
| `/` | Home |

| `/services` | All Services |
| `/corporate-events` | Corporate Events |
| `/birthday-celebrations` | Birthday Celebrations |
| `/marriage-celebrations` | Marriage Celebrations |

## Contact form

Submissions from `/contact` are sent to **enquiry@preventsmanagement.com** via [FormSubmit](https://formsubmit.co) (no backend required).

**One-time setup:** After the first test submission, FormSubmit emails **enquiry@preventsmanagement.com** an activation link — open it once so future enquiries are delivered.

Optional: copy `.env.example` to `.env` and set `VITE_FORM_SUBMIT_URL` if you use a different form endpoint.

### Message to send your client (copy & paste)
